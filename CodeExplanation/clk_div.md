# clk_div.v 源码说明

## 1. 实现的功能
把板载主时钟（默认 50MHz）分频，产生三个**单拍周期使能脉冲**：1Hz（走时）、500Hz（预留扫描）、2Hz（闪烁/计时基准）。输出的是"每个周期拉高 1 拍"的脉冲，而不是分频时钟，避免时钟歪斜。

## 2. 模块
- `clk_div`：唯一模块，功能=时钟分频/节拍产生。

## 3. 接口
| 方向 | 信号 | 说明 |
| :-- | :-- | :-- |
| 输入 | `i_clk` | 全局主时钟 |
| 输入 | `i_rst_n` | 低有效异步复位 |
| 输出 | `o_flag_1s` | 1Hz 使能脉冲 |
| 输出 | `o_flag_500hz` | 500Hz 使能脉冲 |
| 输出 | `o_flag_2hz` | 2Hz 使能脉冲 |
| 参数 | `CLK_FREQ` | 主频（默认 50_000_000） |
| 参数 | `CNT_WIDTH` | 计数器位宽（默认 32） |

## 4. 代码与需求的对应
- `localparam CNT_1S/CNT_500HZ/CNT_2HZ`：由 `CLK_FREQ` 计算计数阈值 → 对应"1 秒走时、闪烁节拍"的时基需求。
- `always @(posedge i_clk...)` 中三个计数器各自到阈值后回零并把对应 `o_flag_*` 置 1 一拍 → 产生周期脉冲。
- 采用"计数器 + 使能脉冲"而非门控时钟 → 满足代码规范"单时钟域、避免 Clock Skew"。

## 关键代码详解

```verilog
localparam CNT_1S    = CLK_FREQ - 1;
localparam CNT_500HZ = CLK_FREQ / 500 - 1;
localparam CNT_2HZ   = CLK_FREQ / 2 - 1;

always @(posedge i_clk ...) begin
    if (cnt_1s_r >= CNT_1S) begin
        cnt_1s_r  <= 0;
        o_flag_1s <= 1'b1;   // 到阈值这一拍输出高
    end else begin
        cnt_1s_r  <= cnt_1s_r + 1'b1;
        o_flag_1s <= 1'b0;
    end
    // 500Hz / 2Hz 同理
end
```

- **阈值怎么来**：要"每 `CLK_FREQ` 个时钟产生一次 1Hz"，计数从 0 数到 `CLK_FREQ-1` 正好 `CLK_FREQ` 拍，所以阈值取 `CLK_FREQ-1`。500Hz 即每 `CLK_FREQ/500` 拍一次；2Hz 即每 `CLK_FREQ/2` 拍一次。
- **为什么输出只高 1 拍**：到阈值那拍把 `o_flag_*` 置 1，下一拍进 `else` 又置 0，于是形成"单拍脉冲"。下游模块用它当"这一秒到了/该翻转了"的使能，而不是拿它当时钟（避免门控时钟、时钟歪斜）。
- **复位**：`cnt` 清零、三个 flag 清零，保证上电后从第 0 拍开始稳定计数。
