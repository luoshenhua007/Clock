# rtc_counter.v 源码说明

## 1. 实现的功能
实时时钟/日期计数。按 1Hz 使能走时，维护 BCD 的 时:分:秒 与 年/月/日；支持字段 +1/−1 编辑；日期自动处理闰年与大小月，并在年月调整后收缩日（如 2/29→平年、31→30 天月）。

## 2. 模块
- `rtc_counter`：唯一模块，功能=时间/日期计数与设置。

## 3. 接口
| 方向 | 信号 | 说明 |
| :-- | :-- | :-- |
| 输入 | `i_clk`,`i_rst_n` | 时钟/复位 |
| 输入 | `i_flag_1s` | 秒使能脉冲 |
| 输入 | `i_set_en` | 时间编辑：暂停走时并允许改 时/分/秒 |
| 输入 | `i_date_edit` | 日期编辑：**不暂停**走时，允许改 年/月/日 |
| 输入 | `i_field[2:0]` | 字段：0=时 1=分 5=秒 2=年 3=月 4=日 |
| 输入 | `i_inc`,`i_dec` | 字段 +1/−1 单拍 |
| 输出 | `o_hour/o_minute/o_second` | BCD 时分秒 |
| 输出 | `o_year[15:0]` | BCD 四位年 |
| 输出 | `o_month/o_day` | BCD 月/日 |

## 4. 代码与需求的对应
- BCD 位寄存器（`s_t_r..y0_r` 等）：时分秒与年月日均以 BCD 存储，直接可显示。
- 函数 `bcd2_inc/dec`、`bcd4_inc/dec`：BCD 字段增减，避免二进制借位乱码。
- `is_leap()`：由 BCD 位直接推导闰年（`(2*y1+y0)%4` 等），满足闰年需求且无需除法。
- `max_day()`：返回当月最大天数（28/29/30/31），满足大小月需求。
- 走时段（`i_flag_1s && !i_set_en`）：秒→分→时进位，`midnight_w` 检测 23:59:59 跨天，再推进日/月/年 → 对应"时间从 00:00 计到 23:59、日期自动进位"。
- 编辑段：时间字段在 `i_set_en` 下可调；日期字段在 `i_date_edit` 下可调，并做日收缩 → 对应"时间/日期设置界面"。

## 关键代码详解

**（1）BCD 字段增减函数**
```verilog
function [7:0] bcd2_inc(hi, lo);   // 个位到 9 就进位
    bcd2_inc = (lo==4'h9) ? {hi+1, 4'h0} : {hi, lo+1};
endfunction
function [7:0] bcd2_dec(hi, lo);   // 个位到 0 就借位
    bcd2_dec = (lo==4'h0) ? {hi-1, 4'h9} : {hi, lo-1};
endfunction
```
- BCD 每位 4 bit，十位在高半字节、个位在低半字节。
- 个位满 9 加一→个位变 0、十位加一；个位为 0 减一→个位变 9、十位减一。这样避免二进制自减出现 `0x10-1=0x0F` 的非法码。

**（2）闰年（无需除法）**
```verilog
ymod4 = (2*y1 + y0) & 3;   // 整个年份 %4（因为 1000、100 都是 4 的倍数，只有十位/个位影响）
cmod4 = (2*y3 + y2) & 3;   // 世纪两位 %4
is_leap = (ymod4==0) && ((y1!=0)||(y0!=0)||(cmod4==0));
```
- 数学依据：`Y = 1000*y3+100*y2+10*y1+y0`，对 4 取模时前两项为 0，只剩 `10*y1+y0 ≡ 2*y1+y0 (mod 4)`。
- `Y%100==0` 等价于"末两位都是 0"（`y1==0&&y0==0`）；`Y%400==0` 还要世纪两位能被 4 整除。条件 `(y1!=0||y0!=0||cmod4==0)` 即"不是整百年，或整百年且世纪能被 4 整除"。
- 好处：纯组合逻辑，不占用除法器，且对 2000（闰）/2100（非闰）都正确。

**（3）当月天数与月增减**
```verilog
max_day: 2月→leap?29:28；4/6/9/11→30；其余→31
month_inc: 12→01；个位 9→十位+1；否则个位+1
month_dec: 01→12；个位 0→借位；否则个位-1
```

**（4）用"下一拍中间量 + 非阻塞提交"避免竞争**
```verilog
// 先把下一拍值默认等于当前值
{s_t_n,s_u_n} = {s_t_r,s_u_r};
...
// 在 *_n 上按顺序修改（阻塞赋值，可立即被后续判断使用）
if (...) {d_t_n,d_u_n} = ...;
// 最后统一非阻塞提交
s_t_r <= s_t_n; ...
```
- 好处：同一拍内"日/月/年相互约束"（如月改了要把日收缩）可以按顺序在 `*_n` 上计算，最后一次性提交，避免多处非阻塞赋值互相读到旧值。

**（5）走时与跨天**
```verilog
if (i_flag_1s && !i_set_en) begin
    if (sec_bcd==59) begin sec=00;
        if (min_bcd==59) begin min=00; hour= hour==23?0:inc; end
        else min=inc;
    end else sec=inc;
    if (midnight_w) begin      // 旧值 23:59:59
        if (day==max_d) begin day=01; month(12→年进一位) end
        else day=inc;
    end
end
```
- `midnight_w` 用**当前（旧）值**判断"是不是 23:59:59"，是则跨天：日到当月最大就进月（12 月再进年），否则日加一。
- 整个走时块被 `!i_set_en` 门控：**只有校时暂停**，改日期/看日期都不影响。

**（6）编辑后的日收缩**
```verilog
dm = max_day(新月份, is_leap(新年));
if (日 > dm) 日 = dm;
```
- 解决"先把日设 31，再把月改成 30 天月/2 月"导致的非法日期，自动收缩到该月最大天。

**（7）输出拼接**
```verilog
assign o_hour = {h_t_r, h_u_r};   // 十位在高、个位在低 → 一个 BCD 字节
```
- 内部为便于 BCD 增减把字段拆成"十位/个位"两个 4 位寄存器；对外用 `{}` 拼成一个 8 位 BCD 字节（如 `h_t=2,h_u=3` → `8'h23`）。
- `assign` 是组合逻辑，实时反映寄存器状态，仅作只读镜像。

## 说明（原"疑问"）
- 字段编码为 `0=时 1=分 5=秒 2=年 3=月 4=日`，**非连续**（秒用 5）。上层必须按此映射光标到字段码，不能按 0/1/2/3 连续理解。
- "年"编辑对**完整四位 BCD** 递增/递减（2026→2027，9999↔0000 回绕），不是只改后两位。

## 待修改事项（统一处理）
- 逻辑已确认，无功能性问题。
- 可选整理：把非连续字段码（秒=5）改为连续编码（如 0..5），使上层映射更直观；因涉及顶层联动，归入统一修改时一并考虑。
- 其余无需修改。
