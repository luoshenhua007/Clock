# tb_clk_div.v 源码说明

## 1. 实现的功能
对 `clk_div` 的仿真测试：验证 1Hz/500Hz/2Hz 三个使能脉冲的周期与首个脉冲时刻。为加速仿真，参数化缩小 `CLK_FREQ=1000`。

## 2. 模块
- `tb_clk_div`：Testbench，例化 `clk_div`（DUT）。

## 3. 接口/激励
- 产生 10ns 周期时钟；复位在负沿释放；负沿采样标志。
- 关键参数：`CLK_FREQ=1000`、`CNT_WIDTH=16`。

## 4. 测试内容与对应需求
- 统计 5000 周期内 `flag_1s/500hz/2hz` 脉冲数与首次出现周期 → 验证分频正确性。
- 断言：1Hz=5 次且首现 @1000；500Hz=2500 次首现 @2；2Hz=10 次首现 @500。
- 对应需求：为走时/闪烁提供准确节拍。

## 关键代码详解

```verilog
@(negedge clk); rst_n = 1;          // 在负沿释放复位
repeat (5000) begin
    @(negedge clk);                 // 在负沿采样标志
    cycles = cycles + 1;
    if (flag_1s) begin cnt_1s=cnt_1s+1; if(first<0) first=cycles; end
end
```
- **为什么在负沿释放/采样**：DUT 在正沿更新寄存器；若在正沿同时读写会读到旧值（竞争）。负沿采样时正沿的更新已稳定，结果确定。
- **first@1000 的含义**：计数器从 0 数到 999（共 1000 拍）后第 1000 个负沿采到首个脉冲，正好验证周期=1000。
- **参数缩小**：`CLK_FREQ=1000` 让 1Hz=1000 拍，避免真实 50M 拍仿真过慢；逻辑等价。

## 说明（原"疑问"）
- 采样在负沿进行，避免与 DUT 正沿更新竞争。
