# countdown.v 源码说明

## 1. 实现的功能
倒计时（HH:MM:SS，上限 23:59:59）。可设置初值（时/分/秒），支持开始/暂停、复位到初值；逐秒 BCD 递减，到 00:00:00 置完成标志并停表，同时显示还原为默认初值。

## 2. 模块
- `countdown`：唯一模块，功能=倒计时配置、运行控制与递减。

## 3. 接口
| 方向 | 信号 | 说明 |
| :-- | :-- | :-- |
| 输入 | `i_clk`,`i_rst_n` | 时钟/复位 |
| 输入 | `i_flag_1s` | 秒使能 |
| 输入 | `i_set_en` | 设置模式（调整初值字段） |
| 输入 | `i_field[1:0]` | 0=时 1=分 2=秒 |
| 输入 | `i_inc`,`i_dec` | 字段增减 |
| 输入 | `i_run` | 开始/暂停切换（脉冲） |
| 输入 | `i_reset` | 复位到初值（脉冲） |
| 输出 | `o_h/o_m/o_s` | 当前倒计时 BCD |
| 输出 | `o_done` | 已完成 |
| 输出 | `o_running` | 运行中 |
| 参数 | `INIT_H/INIT_M/INIT_S` | 默认初值（顶层设为 00:01:00） |

## 4. 代码与需求的对应
- 配置寄存器 `ch_r/cm_r/cs_r` 与工作计数 `wh_r/wm_r/ws_r` 分离 → 设置与运行互不干扰。
- `i_set_en` 段：调整初值并同步到工作值（字段范围：时 0..23、分/秒 0..59）→ 对应"可设定起始倒计时时间"。
- `i_run` 段：`done_r || zero_w` 时重新载入初值并运行，否则切换运行/暂停 → 对应"暂停与重新开始"。
- `i_reset`：工作值回到初值并停止 → 对应"复位/重新开始"。
- 递减段：秒用 `bcd2_dec` 做 **BCD 自减**（避免 xx.x0→乱码），秒借位到分、分借位到时 → 对应"从 01:00 倒到 00:00"。
- 到零：置 `done_r`、停表，并把工作值还原为初值 → 对应"结束提示 + 显示默认值"。

## 关键代码详解

**（1）配置与工作值分离 + 设置同步**
```verilog
if (i_set_en) begin
    run_r <= 0; done_r <= 0;
    wh_r <= ch_r; wm_r <= cm_r; ws_r <= cs_r;   // 工作值跟随初值
    ... 按 i_field 调整 ch/cm/cs ...
end
```
- 用户改的是"初值"`ch/cm/cs`；同时把工作值 `wh/wm/ws` 同步过来，所以设置界面显示的就是初值。

**（2）开始/暂停/复位**
```verilog
if (i_reset) begin run=0; done=0; 工作值<=初值; end
else if (i_run) begin
    if (done_r || zero_w) begin run=1; done=0; 工作值<=初值; end // 结束/零时重开
    else run_r <= ~run_r;                                         // 否则切换
end
```
- `i_run` 是单拍脉冲（KEY3 短按）：完成或为 0 时按一下=从初值重新开始；否则=运行/暂停切换。

**（3）BCD 逐秒递减与借位**
```verilog
if (run_r && i_flag_1s) begin
    if (zero_w) begin run=0; done=1; 工作值<=初值; end   // 到 0 完成
    else if (ws_r==0) begin ws=59;
        if (wm_r==0) begin wm=59; wh = wh==0?0:dec; end
        else wm = dec(wm);
    end else ws = bcd2_dec(ws);                          // 关键：BCD 自减
end
```
- 秒为 0 时向分借位（分也为 0 再向时借位，时不为 0 才减）。
- 递减用 `bcd2_dec` 而非二进制减法：否则 `0x10-1=0x0F` 是非法 BCD，显示会乱码。

**（4）到零当拍完成并回初值**
- `zero_w` 为 1（即已是 00:00:00）时置 `done`、停表，并把工作值写回初值 → 显示立刻回到默认值，而不是停在 00:00:00。

- `i_reset` 由顶层在 KEY3 长按时产生，用于复位到初值。
