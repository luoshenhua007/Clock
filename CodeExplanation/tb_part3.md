# tb_part3.v 源码说明

## 1. 实现的功能
集成测试之三：验证【闹钟/倒计时 · 显示】模式——闹钟选择与启停用、倒计时视图、启停与默认初值。

## 2. 模块
- `tb_part3`：Testbench，例化 `top_digital_clock`，开关置于"闹钟/倒计时·显示"。

## 3. 接口/激励
- 默认进入显示闹钟1；KEY1 切闹钟、KEY2 切倒计时、KEY3 控制。

## 4. 测试内容与对应需求
- 默认显示闹钟1且停用；KEY3 启用/停用闹钟。
- KEY1 切到闹钟2；KEY2 切倒计时视图，初值应为 00:01:00。
- KEY3 启动倒计时，快进约 1s 后应为 00:00:59；再按 KEY3 暂停并冻结。
- 对应需求：3 组闹钟显示/启停用、倒计时显示与启停。

## 关键代码详解

**（1）进入 AC 组显示**
```verilog
sw_group = 0; sw_edit = 1;   // 闹钟/倒计时·显示
chk("A2", u_dut.ac_sel==0 && u_dut.alarm_idx==0, "alarm1 view");
```
- 用开关电平组合进入模式；断言当前显示对象与编号。

**（2）启停用闹钟**
```verilog
tap(2);                                   // KEY3
chk("A4", u_dut.alm_en[0]==1, "alarm1 enabled");
tap(2);                                   // 再按关闭
```
- 显示页 KEY3 对闹钟是"切换使能"，测试连续按两次验证开→关。

**（3）倒计时启停与计时验证**
```verilog
tap(1);                       // KEY2 切倒计时视图
chk("C2", ch==0 && cm==1 && cs==0, "init 00:01:00");
tap(2);                       // KEY3 启动
cyc(CLK_FREQ);                // 走约 1 秒
chk("C4", cm==0 && cs==59, "counted down 1s");
```
- 用缩小主频让"1 秒=1000 拍"，走 1000 拍后断言减了 1 秒，验证运行与递减。
