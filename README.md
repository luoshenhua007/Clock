# 基于 FPGA 的多功能电子表设计文档 (Multi-Function Digital Clock)

本文档为基于 FPGA 的多功能电子表设计项目的规范与实施指南，包含项目大纲、系统架构设计思路、工作流计划、模块划分及代码规范。

## 0. 题目及要求 (Topic and Requirements)

### 0.1 设计题目：（二）多功能电子表

+ 功能描述：
   设计FPGA模块模拟多功能电子表的工作过程，具备多种功能
+ 功能要求及验收要点：
  1. **时间显示界面**，要求从00:00点计到23:59。
  2. **日期显示界面**，要求显示当前日期，包含年、月、日。
  3. **调整时间界面**，即可以设置或更改当前的时间（小时、分）。
  4. **日期设置界面**。可以设置当前的日期，比如2017年09月22日。要求支持闰年与大小月的识别。
  5. **闹钟设置界面**，可以设置3个闹钟，闹钟时间到了后会用LED闪烁提醒，提醒时间持续5秒，如果提醒时按解除键，则该闹钟解除提醒，如果闹钟响时没有按键或按其他按键，则响完5秒之后暂停，然后10秒钟后重新提醒一次后解除。
  6. **倒计时功能**。可以设定倒计时的起始时间，比如1分钟，然后开始倒计时，从01:00倒计时到00:00，然后LED灯闪烁5秒钟。倒计时中间可以暂停或重新开始。
  7. 电子表只有六个按键。请**只使用六个按键**来完成所有功能。

1. 理论：数字电路基础（逻辑、时序、状态设计）
2. 硬件：数字电路（系统）硬件（逻辑编程器件PLD：FPGA 开发板 - xc7a75tfgg484-2）
3. 编程：硬件电路描述语言（HDL）
4. 软件：开发环境（Vivado 2024.2）

## 1. 项目大纲 (Project Outline)

### 1.1 项目背景与目标

本项目旨在利用 Verilog HDL 在 FPGA 开发板上设计并实现一个具备高可靠性、多功能的数字电子表系统。系统通过有限状态机（FSM）管理多界面切换与按键交互，并通过动态数码管扫描与 LED 提示输出状态。

### 1.2 核心功能与验收要求

| 序号 | 功能模块 | 验收要点描述 |
| :--- | :--- | :--- |
| **1** | **时间显示界面** | 24小时制，从 `00:00` 计到 `23:59`（支持秒计数及时分显示/秒显示切换/闪烁提示）。 |
| **2** | **日期显示界面** | 显示当前年月日（如 `2026-09-01`），支持切换或自动轮播显示。 |
| **3** | **时间调整界面** | 可选择并设置/更改当前的时（Hour）、分（Minute）。设置项具备闪烁提示。 |
| **4** | **日期设置界面** | 支持设置当前日期（年、月、日），硬件自动实现**平闰年判别**（2月28/29天）及**大小月识别**（30/31天）。 |
| **5** | **闹钟设置界面** | 1. 支持独立设置 **3组闹钟**。<br>2. 闹钟到点后 **LED 闪烁提醒 5 秒**。<br>3. 提醒期间若按**解除键**，则立即解除提醒。<br>4. 若未按键或按其他键，响完5秒后暂停，**10秒后重新提醒一次**，之后自动解除。 |
| **6** | **倒计时功能** | 1. 可设定起始倒计时时间（如 `01:00` 到 `00:00`）。<br>2. 倒计时结束 LED 闪烁 5 秒。<br>3. 支持倒计时过程中的**暂停与重新开始**。 |
| **7** | **按键复用约束** | **严格限定仅使用 6 个物理按键**完成所有界面的切换、参数增减、闹钟复位及倒计时控制。 |

## 2. 系统设计思路与架构 (System Architecture & Design)

整体架构采用**模块化、分层化设计思想**，包含输入消抖层、顶层控制逻辑（状态机）、数据处理与计数层、以及输出显示驱动层。

```txt
                  +-----------------------------------+
                  |        物理按键 (6个 Key In)       |
                  +-----------------------------------+
                                    |
                                    v
                  +--------------------------------------+
                  |   按键消抖与边沿检测模块 (key_debounce)|
                  +--------------------------------------+
                                    | (Key Pulse Bus)
                                    v
+------------------------------------------------------------------------+
|  主控状态机逻辑 (fsm_controller)                                        |
|  - 界面模式切换 (MODE_TIME, MODE_DATE, MODE_SET_TIME, MODE_SET_DATE...) |
|  - 设置位选择 (Cursor Flash / Select)                                   |
+------------------------------------------------------------------------+
        |                 |                  |                 |
        v                 v                  v                 v
+---------------+ +---------------+ +----------------+ +---------------+
| 实时时钟/日期  | |  闹钟管理模块  | |  倒计时管理模块 | | LED/蜂鸣器提醒 |
| (rtc_counter) | | (alarm_clock) | |  (countdown)   | |  (alarm_led)  |
+---------------+ +---------------+ +----------------+ +---------------+
        |                 |                  |
        +-----------------+------------------+
                          | (BCD Code & Mode Flag)
                          v
        +-----------------------------------+
        |  数码管动态扫描驱动 (seg_driver)    |
        +-----------------------------------+
                          |
                          v
        +-----------------------------------+
        |    硬件数码管 / LED 物理输出        |
        +-----------------------------------+
```

### 2.1 按键与开关分配 (Inputs & Key Mapping)

系统输入：4 按键 KEY1~KEY4（低有效）+ 2 开关 SW4/SW3（**按电平使用**）。
两开关决定「功能组」与「显示/编辑」，KEY 行为随模式变化；除"编辑时间"外计时不停。

**物理映射**：KEY1=E3、KEY2=G4、KEY3=P19、KEY4=R19；SW4=N15、SW3=R17（同手册/XDC）。

**开关档位语义**（拨下=off，拨上=on）：
- SW4：下 → 时间/日期组；上 → 闹钟/倒计时组
- SW3：下 → 显示；上 → 编辑

上电默认两开关均拨下 → **时间/日期·显示**，页=时间；闹钟组默认闹钟1。

| SW4 | SW3 | 模式 |
| :-: | :-: | :-- |
| 下 | 下 | 时间/日期 · 显示（默认） |
| 上 | 下 | 闹钟/倒计时 · 显示 |
| 下 | 上 | 时间/日期 · 编辑 |
| 上 | 上 | 闹钟/倒计时 · 编辑 |

**按键分配（KEY1~KEY4，低有效）**

| 模式 | KEY1 | KEY2 | KEY3 | KEY4 |
| :-- | :-- | :-- | :-- | :-- |
| 时间/日期 · 显示 | 时间 ↔ 日期 | 时间：12/24h；日期：年月日 ↔ 星期 | 无 | 解除闹钟 |
| 闹钟/倒计时 · 显示 | 闹钟1/2/3 切换（非闹钟视图先回闹钟1） | 显示倒计时 | 闹钟：启/停用当前闹钟；倒计时：启/停，长按=复位 | 解除闹钟 |
| 时间/日期 · 编辑 | 循环修改位：时/分/秒、年/月/日 | +（长按连加） | −（长按连减） | 解除闹钟 |
| 闹钟/倒计时 · 编辑 | 循环修改位：闹钟=时/分；倒计时=时/分/秒 | +（长按连加） | −（长按连减） | 解除闹钟 |

**细则**
- 编辑仅作用于进入前正在显示的界面；编辑中 SW4 无效（不切组），退出编辑后按 SW4 档位显示。
- 时间/日期编辑界面强制 24h 制与年月日显示，退出编辑恢复进入前的视图（12/24h、年月日/星期）；闹钟/倒计时仅 24h 制。
- 星期编码：周一=1 … 周日=7；日期编辑后星期自动更新。
- 12/24h：内部恒为 24h 计时，12h 仅显示换算 `0→12(A)`、`13..23→1..11(P)`，第 8 位显示 A/P。
- 除编辑时间外时钟不停（日期查看/编辑、闹钟响铃、倒计时运行均不影响）。
- KEY4 在任何模式/编辑状态都用于解除（全部）闹钟；倒计时不受影响。
- 闹钟到点按“时:分”在分跳变沿触发：响 5s→静默 10s→再响 5s 自动结束。LED 分工：LED1/2/3(AA6/V7/W7)=闹钟1/2/3，LED4(AB7)=倒计时结束。
- 闹钟/倒计时组返回显示时**保持上次所选对象**（闹钟1/2/3 或倒计时），仅上电默认闹钟1；从倒计时视图按 KEY1 回到闹钟1。

**显示格式**（pos7=最左）
1. 时间：`HH.MM.SS`（第1~6位），第7位空，第8位 12h 时 `A/P`（24h 空）。
2. 日期：`YYYY.MM.DD` 占满 8 位。
3. 星期：第1位显示 1~7，其余灭。
4. 闹钟（24h）：左4 `HH.MM`，第5~6位空，第7位常驻 `-`，第8位编号1/2/3；停用时左4显示 `----`。默认各闹钟 `00:00` 且停用。
5. 倒计时（上限 23:59:59，默认 00:01:00）：左6 `HH.MM.SS`，第7位空；第8位**运行中=顺时针每秒滚动圈**，暂停/复位/结束=`-`。倒计时结束 LED4 闪烁 5s，同时显示恢复为默认初值。

### 2.2 核心算法与逻辑设计

1. **分频与基准时钟（Clock Divider）**：
   * 将板载 50MHz 时钟分频生成 1Hz（1秒产生一个脉冲标志 `flag_1s`）、500Hz（数码管扫描）、2Hz（闪烁控制）。
2. **闰年与大小月判别逻辑（Calendar Logic）**：
   * 大月（1, 3, 5, 7, 8, 10, 12月）：31天。
   * 小月（4, 6, 9, 11月）：30天。
   * 闰年判断条件：`(Year % 4 == 0 && Year % 100 != 0) || (Year % 400 == 0)`。若为闰年，2月为 29 天，否则为 28 天。
3. **闹钟二次提醒状态机（Alarm FSM）**：
   * **IDLE**：监听当前时间与 3 组闹钟时间匹配。
   * **ALARM_1**：匹配成功，LED 闪烁，启动 5s 计时器。若收到 `KEY4`，直接转入 IDLE；5s 结束未按键，转入 SNOOZE。
   * **SNOOZE**：静音等待 10s。10s 到达后进入 ALARM_2。
   * **ALARM_2**：二次 LED 闪烁 5s。时间到或按解除键后均返回 IDLE。
4. **倒计时模块（Countdown Unit）**：
   * 采用独立计数器，按秒递减，递减至 `00:00` 时触发 5 秒 LED 提示脉冲。

### 2.3 模块划分与接口约定

| 模块 | 主要输入 | 主要输出 | 说明 |
| :--- | :--- | :--- | :--- |
| `clk_div` | `clk`, `rst_n` | `flag_1s`, `flag_500hz`, `flag_2hz` | 分频，产生周期使能脉冲（非时钟脚） |
| `key_debounce` | `clk`, `rst_n`, `key_in[5:0]` | `key_pulse[5:0]`, `key_hold[5:0]` | 消抖 + 单拍脉冲 + 长按标志 |
| `fsm_controller` | `clk`, `rst_n`, `key_pulse[5:0]` | `view`, `edit`, `cursor[1:0]` | 时间/日期两页切换 + 就地编辑子状态 |
| `rtc_counter` | `clk`, `rst_n`, `flag_1s`, `set_en`, `date_edit`, `field[2:0]`, `inc/dec` | `hour` / `minute` / `second`, `year[15:0]`, `month` / `day`（BCD） | 时/分/秒与年/月/日计数（闰年、大小月）；`set_en`(时间编辑,暂停走时) 字段 0/1/5=时/分/秒；`date_edit`(日期编辑,不暂停) 字段 2/3/4=年/月/日 |
| `alarm_clock` | `clk`, `rst_n`, `flag_1s`, `set_en`, `idx[1:0]`, `fld[1:0]`, `inc/dec`, `cur_hour` / `cur_min`, `ack` | `ring`, `ring_no[1:0]`, `en[2:0]`, `sel_hour` / `sel_min` | 3 组闹钟 + 5s/10s 二次提醒 FSM；字段 0=时 1=分 2=使能切换；解除键边沿即时响应 |
| `countdown` | `clk`, `rst_n`, `flag_1s`, `set_en`, `fld`, `inc/dec`, `run`, `reset` | `min` / `sec`, `done`, `running` | 倒计时（分 00~99 / 秒 00~59）：设定、开始/暂停、复位、结束重开 |
| `alarm_led` | `clk`, `rst_n`, `flag_1s`, `flag_2hz`, `alarm_ring`, `cnt_done` | `led` | 响铃 2Hz 闪烁 / 倒计时结束 5s 闪烁 |
| `seg_driver` | `clk`, `rst_n`, `flag_500hz`, `digit[31:0]`, `dp[7:0]`, `blank[7:0]` | `seg[7:0]`, `sel[7:0]` | 八位动态扫描 + 7 段译码 + 小数点/熄灭（极性参数化） |
| `top_digital_clock` | `clk`, `rst_n`, `key[5:0]` | `seg[7:0]`, `sel[7:0]`, `led` | 顶层集成：6 键译码、八位显示选通、光标闪烁 |
| `top_digital_clock_board` | `sys_clk`, `btn[3:0]`, `sw1`, `sw2` | `seg[7:0]`, `sel[7:0]`, `led` | 板上封装：上电复位 + 引脚分组映射（供 XDC） |

## 3. 项目工作流与进度安排 (Workflow & Schedule)

### 3.1 总体开发流程

采用 **"文档驱动 + 自底向上实现 + 逐级验证"** 的迭代流程，每个环节通过对应验证标准后方可进入下一环节：

```txt
需求分析/框图绘制 → 模块接口定义 → 底层模块编码 → 模块级仿真
        → 顶层集成 → 集成仿真 → 综合/约束/实现 → 时序收敛
        → 上板在线调试(ILA) → 功能验收 → 文档归档
```

**Phase 2 详细记录：**

* `clk_div.v`：参数化 `CLK_FREQ`，产生 1Hz / 500Hz / 2Hz 单拍使能脉冲（非时钟脚，避免 Clock Skew）。
* `key_debounce.v`：两级同步消抖 + 单拍按下脉冲 `o_key_pulse` + 长按标志 `o_key_hold`（默认 20ms 消抖 / 0.5s 长按阈值，均参数化）。
* `tb_clk_div.v` / `tb_key_debounce.v`：覆盖分频周期、带抖动的短按、释放、长按、复位等场景，全部断言 PASS。
* **Vivado xsim 验证**：已将 4 个文件加入工程（RTL 入 sources_1，TB 入 sim_1），行为级仿真输出 `ALL TESTS PASSED`。注意 xsim 默认只跑 1000ns，需在 Tcl Console 输入 `run all`（tb_clk_div 需约 50.1us，tb_key_debounce 需约 1.43us）才会到 `$finish`。
* 为消除 xsim 的 `module has no timescale` 警告，已为 `clk_div.v`、`key_debounce.v` 补充 `` `timescale 1ns / 1ps ``。
* 排障记录：`key_debounce.v` 曾意外被写坏为全零字节文件（5816B 全 0），已重建恢复；若再遇类似损坏，在 Vivado 中 Remove File 后重新 Add Files 即可。
* 调试经验：TB 若在时钟边沿采样会与模块 NBA 更新产生读旧值竞争，应在上沿后 1/4 周期采样、负沿计数；实际时序参考——脉冲约在按键变化后 13~14 拍被计数，hold 约 40~41 拍拉高，采样等待需留足余量。

**Phase 3 详细记录：**

* `rtc_counter.v`：BCD 存储的 时/分/秒 与 年/月/日 计数。闰年由 BCD 位直接推导（无需除法，覆盖 2000/2100 世纪），月长 28/29/30/31 天组合判断；设置模式下字段 +1/-1（0=时 1=分 2=年 3=月 4=日），年月调整后自动收缩日（如 2/29->平年、31->30 天月）。初值可参数化（`INIT_YEAR` 等）。
* `alarm_clock.v`：3 组闹钟（时/分 + 使能位）。仅在分钟跳变沿触发提醒，避免同分钟重复；状态机 IDLE->ALARM_1(5s, 可解除)->SNOOZE(10s)->ALARM_2(5s)->IDLE。字段调整：时/分/使能切换。
* `countdown.v`：分:秒倒计时（分 00~99，秒 00~59 回绕）。支持设定初值、开始/暂停切换、复位、结束后按开始重新载入。减到 00:00 当拍置完成标志并停表。
* 对应 TB 覆盖：时间/日期进位、闰年（2024/2000 闰、2100 非闰）、大小月、字段增减与日收缩回绕；闹钟响铃/解除/二次提醒全时序、同分钟不重复、关闭不响；倒计时递减/借位/暂停/结束/复位/重启。
* 设计决策：全部 BCD 递增/递减用函数封装（`bcd2_inc/dec`、`bcd4_inc/dec`），寄存器统一非阻塞提交，杜绝竞态；TB 输入统一在时钟负沿改变、正沿采样，保证确定性。
* **Vivado xsim 验证**：三个 TB 均加入工程并在 xsim 中运行通过；`tb_rtc_counter` 需 `run all`（含两段 86400s 快进，耗时约毫秒级仿真）后输出 `ALL TESTS PASSED`。
* 排障记录：多场景共享时钟导致相互推进；`countdown` 退出设置模式时工作计数需在下降沿同步初值；到达 00:00 当拍置 done（初版滞后一拍）。

**Phase 4 详细记录：**

* `fsm_controller.v`：MODE/SEL 状态机。6 模式循环（时间/日期/时间设置/日期设置/闹钟/倒计时），SEL 推进各设置界面的光标（时/分、年/月/日、闹钟 3 组 × {时,分,使能}、倒计时 分/秒/运行视图）。其余按键译码、显示选通置于顶层组合逻辑。
* `seg_driver.v`：500Hz 动态扫描六位数码管，BCD->7 段（含 A~F），逐位小数点与熄灭控制（闪烁/空白），位选/极性参数化。
* `alarm_led.v`：闹钟响铃期间按 2Hz 闪烁（时长由闹钟状态机决定）；倒计时 done 上升沿启动内部 5s 闪烁。
* `top_digital_clock.v`：顶层集成，参数（CLK_FREQ / 消抖 / 长按）可配以便仿真。完成 6 键到各子模块的操作译码、按模式的六位显示选通与光标闪烁。
* `tb_top_digital_clock.v` 集成仿真覆盖：MODE 循环切换、时间/日期字段增减、闹钟设为 00:00 并到点响铃/解除、倒计时设定->运行->完成->复位。
* **Vivado xsim 验证**：`tb_top_digital_clock` 已加入工程并运行通过；需 `run all`（含约 60s 快进等待闹钟，仿真耗时至约 0.7ms）后输出 `ALL TESTS PASSED`。
* 关键决策：闹钟解除由"仅秒节拍内响应"改为**边沿即时解除**，按键响应不再受 1s 节拍限制。
* 排障记录：task 形参传条件表达式只在调用时求值一次，导致等待条件永不成立——改用流程内联实时采样；alarm 响铃的解除需落在秒节拍（改即时解除后不再受限）。
* 已知简化（后续可优化）：日期设置界面通过年低 2 位调整整年；闹钟使能用小数点指示、无独立"开/关"标签；段码/位选极性等上板参数在 Phase 5 按板适配。

**Phase 5 详细记录：**

* 依据 HX7A75A 手册引脚表完成约束 `top_digital_clock.xdc`：时钟 Y18@50MHz；4 按键 E3/G4/P19/R19（低有效）；2 开关 N14/P16（低触发）作 KEY4/KEY5；共阳段码 AB18/U17/U18/P14/R14/R18/T18/N17（**低点亮，实测**）；位选 **低有效（低者点亮，实测）**，o_sel[0]=AA18 为最左管；LED AA6 高点亮。
* 板上实测（bring-up）：段码须取反输出；位选须低有效（高有效会把未选中的 7 只全点亮造成混叠"全 8"）；扫描每位前预留熄灭尾段防残影；时分/分秒冒号点置于 pos6/pos4。时间界面走秒上板验证通过（Phase 6 收尾中）。
* 待办（Phase 6）：闹钟/日期/倒计时等全部模式上板逐项验收、ILA 在线调试。
* 板上封装 `top_digital_clock_board.v`：片上电复位（~84ms），4 按键+2 开关拼成 i_key[5:0]。
* 显示升级为 **8 位**：日期界面可完整显示 `YYYY-MM-DD`，闹钟界面首位显示闹钟编号。显示扫描/译码内联于顶层（防残影加换位熄灭尾段；`seg_driver` 保留作模块级参考）。
* 综合结果：xc7a75tfgg484-2，0 错误 0 严重告警，资源占用极小，时序全满足（Setup WNS=14.245ns, Hold WNS=0.120ns）。

## 4. Verilog 代码规范 (Coding Standards)

为了保证项目代码的可读性、可维护性及可综合性，严格遵守以下规范：

### 4.1 命名规范 (Naming Conventions)

* **文件与模块名**：采用小写字母加下划线，与模块名保持一致（如 `key_debounce.v`）。
* **时钟与复位信号**：统一命名为 `clk`（或 `sys_clk`）和 `rst_n`（低电平有效异步复位）。
* **输入/输出信号**：输入以 `i_` 或 `in_` 开头，输出以 `o_` 或 `out_` 开头（例：`i_clk`, `i_rst_n`, `o_seg_data`）。
* **内部寄存器/线网**：`reg` 变量加 `_r` 尾缀，`wire` 变量加 `_w` 尾缀；按键脉冲采用 `_pos` 或 `_pulse` 尾缀。
* **参数与状态机常量**：全部大写，单词间用下划线分隔（如 `STATE_IDLE`, `MONTH_FEB`）。

### 4.2 结构与书写风格 (Style & Rules)

1. **三段式状态机**：所有 FSM 必须采用**标准三段式**描述（状态同步更新、次态组合逻辑判断、状态输出逻辑）。
2. **时序与组合逻辑分离**：
   * 时序逻辑（`always @(posedge clk or negedge rst_n)`）统一采用**非阻塞赋值**（`<=`）。
   * 纯组合逻辑（`always @(*)` 或 `assign`）统一采用**阻塞赋值**（`=`）。
3. **禁止锁存器（No Latches）**：`if-else` 必须完整，`case` 必须包含 `default`，严禁产生不必要的 Latch。
4. **单时钟域同步设计**：尽量使用全局主时钟，内部次级时钟/周期脉冲（如 1Hz）使用**使能标志位（Enable Pulse）**而非直接用作时钟脚（避免 Clock Skew）。
5. **注释规范**：每个文件头部必须包含模块功能简介、输入输出说明及修改记录；关键判断逻辑（如闰年算法、状态切换条件）必须附带明晰注释。

### 4.3 仿真与验证规范 (Simulation & Verification)

1. 每个模块必须配套独立 Testbench，命名为 `tb_<module>.v`。
2. 仿真时钟周期通过 `parameter`/`localparam` 定义，避免散落的绝对延时导致后期维护困难。
3. 关键边界用例必须覆盖：`23:59 -> 00:00`、月末翻月、平/闰年（如 2000、2024、2100）、闹钟 5s/10s 二次提醒时序、倒计时暂停/恢复。
4. 遵循 **"模块级仿真 → 集成仿真 → 上板验证"** 三级验证顺序；上板调试优先使用 **ILA** 观测内部信号。
5. 可在 Testbench 中使用 `$error` / `$fatal` 自动比对预期值，配合脚本实现自动化回归，防止改 A 坏 B。

## 6. 扩展功能与改进建议 (Extensions & Suggestions)

在满足验收要求的基础上，以下扩展可显著提升系统**实用性、健壮性与可维护性**，建议按优先级逐步实施。

### 6.1 功能增强类

| 建议 | 说明 | 优先级 |
| :--- | :--- | :--- |
| 秒数显示 / 时分秒轮播 | 六位数码管在「时:分」与「分:秒」间自动轮播或按键切换，便于校时观察。 | 中 |
| 蜂鸣器声音提醒 | 闹钟/倒计时结束由 LED 扩展至蜂鸣器（若开发板带蜂鸣器），提升提醒效果。 | 中 |
| 上电记忆 | 将时间/闹钟设置存入 BRAM，上电自动恢复（断电保持需外接 RTC/EEPROM，可作硬件扩展课题）。 | 中 |
| 整点报时 | 每小时整点 LED/蜂鸣器短提示，贴近真实电子表。 | 低 |
| 星期显示 | 依据年月日推算星期（蔡勒公式），日期界面附加显示周几。 | 低 |
| 12/24 小时制切换 | 支持制式切换与 AM/PM 指示。 | 低 |

### 6.2 交互优化类

| 建议 | 说明 | 优先级 |
| :--- | :--- | :--- |
| 长按连加/连减 | 按住 UP/DOWN 超过阈值（如 0.5s）后自动循环递增/递减，大幅提升设置速度。 | 高 |
| 短按/长按区分 | 如 KEY5 短按切换、长按复位，缓解 6 键不足。 | 高 |
| 光标闪烁提示 | 当前修改位以 1~2Hz 闪烁（2Hz 人眼辨识度最佳），设置位置一目了然。 | 中 |
| 保存确认与取消 | 设置界面退出时按 ACK 保存、按 MODE 放弃本次修改，防止误触。 | 低 |

### 6.3 工程与质量类

| 建议 | 说明 | 优先级 |
| :--- | :--- | :--- |
| 参数化与宏定义 | 分频计数阈值、扫描频率、闹钟数量统一用 `parameter`/`` `define `` 定义，便于移植到不同开发板。 | 高 |
| 单时钟域 + 使能脉冲 | 次级时钟一律采用 `flag_1s` 等使能信号，杜绝直接分频作时钟脚（避免毛刺与 Skew）。 | 高 |
| 动态扫描防闪烁 | 扫描频率 ≥ 500Hz（每只数码管刷新率 ≥ 60Hz），位选译码使用无毛刺设计。 | 高 |
| ILA 在线调试 | 集成逻辑分析仪直接观测 `fsm_state`、计数寄存器，上板定位问题效率远高于反复仿真。 | 中 |
| 自动化回归仿真 | 用脚本批量运行各模块 Testbench，配合断言比对输出，防止改 A 坏 B。 | 中 |
| 上电自检 | 上电数码管显示 `8.8.8.8`、LED 全亮，快速确认硬件通路完好。 | 低 |

### 6.4 建议实施顺序

**基础功能验收 → 长按连加 / 光标闪烁（交互优化）→ 上电记忆 / 整点报时（功能增强）→ 12/24 小时制与星期显示（锦上添花）**

建议先确保 7 项验收要点全部达标，再按上述顺序逐项添加扩展功能，每加一项均补充对应 Testbench 与回归验证。

## 7. 开发风险与注意事项 (Risks & Notes)

| 风险点 | 影响 | 预防措施 |
| :--- | :--- | :--- |
| 分频时钟直接驱动逻辑 | 时钟毛刺/歪斜导致功能偶发异常 | 统一使用全局时钟 + 使能脉冲（见 4.2-4） |
| 6 键复用导致状态爆炸 | 状态机复杂、组合易遗漏 | 明确按键优先级（设置 > 响铃 > 正常），状态表评审 |
| 按键抖动误触发 | 设置值跳变、误切换界面 | 消抖（10~20ms）+ 边沿脉冲化 |
| 动态扫描刷新率过低 | 数码管闪烁、亮度不均 | 扫描 ≥ 500Hz，扫描周期均匀 |
| 闰年/大小月边界遗漏 | 日期错位 | 仿真覆盖 2000 / 2024 / 2100 等边界 |
| 时序不收敛 | 上板行为与仿真不一致 | 精简组合逻辑链，复核 WNS/TNS 报告 |
| 上板环境差异 | 引脚/晶振频率与仿真假设不符 | XDC 约束严格对照开发板原理图 |
